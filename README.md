# verificacao-estoque-mercadinho

## Descrição do Problema

Um mercadinho precisa saber quais produtos estão com baixo estoque para reposição.

## Requisitos

- Receber uma lista de produtos com nome e quantidade
- Identificar produtos com quantidade menor ou igual a 5
- Listar os produtos encontrados na ordem em que aparecem
- Indicar que não há alertas se nenhum produto estiver abaixo do limite

## Exemplo de Uso

Entrada:
["Arroz", 3], ["Feijao", 12], ["Leite", 4]

Saída:
Produto: Arroz | Qtd: 3
Produto: Leite | Qtd: 4
